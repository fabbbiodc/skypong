Arquitectura lista ✅

Este gateway Nginx sirve este frontend estático y enruta las APIs y el canal WebSocket seguro (WSS) hacia los microservicios de juego, auth, perfiles y estadísticas.

  • /api/auth → auth-service
  • /api/game + /ws → game-service (Colyseus)
  • /game-engine → game-frontend (cliente propio del engine)
  • /api/profile → profile-service
  • /api/statistics → statistics-service
